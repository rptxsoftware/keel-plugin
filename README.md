# RPTX plugins for Claude Code

**rptx-keel**: teaches Claude to ask [Keel](https://rptxsoftware.com/keel/) why a build or
test is slow: what Keel lowered and why, and what is loading the PC. Needs Keel on Windows,
macOS or Linux.

    /plugin marketplace add rptxsoftware/keel-plugin
    /plugin install rptx-keel@rptx

Details: [keel/README.md](keel/README.md).
